*2. Ejercicio análisis de requerimiento para la página de la escuela - formulación de inscripción de la carrera.*

*Debe tener el requerimiento detallado: Nombre, Descripción, Como se ejecuta, Actor Principal, Precondiciones, Datos de entrada y Salida, Flujo Básico, Flujo Alterno(ERROR), diagramas de caso de uso, reglas de negocio.*

1. **REQUERIMIENTO DE ALTO NIVEL**
- El sistema debe permitir visualizar información institucional.
- El sistema debe permitir consultar programas académicos.
- El sistema debe permitir registro de aspirantes.
- El sistema debe permitir autenticación de usuarios (estudiantes).
- El sistema debe permitir contacto con la institución.
- El sistema debe ser accesible desde dispositivos móviles.


2. **AGRUPACIÓN POR CATEGORÍA**

#### FUNCIONALES
**- RF-01: Consultar información institucional.**

DESCRIPCIÓN: El sistema debe permitir al usuario visualizar información general de la institución como historia, misión, visión y noticias.

ACTOR PRINCIPAL: Visitante

Precondiciones: El usuario debe estar en la página principal.

Datos de Entrada: Selección de opción "Información Institucional"

Datos de Salida: Contenido institucional mostrado en pantalla.

Flujo Básico: 
1. El usuario accede a la página principal.
2. Selecciona la opción “Información institucional”.
3. El sistema muestra la información correspondiente.

Flujo Alterno: Si ocurre error de conexión, el sistema muestra mensaje: “Error al cargar la información. Intente nuevamente.”


**- RF-02: Consultar programas académicos.**
- RF-03: Registro de aspirantes.
- RF-04: Inicio de sesión de estudiantes.
- RF-05: Envío de formulario de contacto


#### NO FUNCIONALES
- RNF-01: Tiempo de respuesta máximo 2 segundos.
- RNF-02: Diseño responsive.
- RNF-03: Seguridad en autenticación.
- RNF-04: Disponibilidad 99% del tiempo.
- RNF-05: Cumplir lineamientos de accesibilidad web.
