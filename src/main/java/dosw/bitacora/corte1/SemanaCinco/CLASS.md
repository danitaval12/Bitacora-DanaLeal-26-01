### ESTIMACIÓN DE TAREAS
En Scrum, la estimación se refiera al proceso de asignar valores relativos a las tareas o historias de usuario para determinar su complejidad o esfuerzo requerido. 
Estas estimaciones se utilizan para planificar los sprints y predecir la velocidad del equipo. Las estimaciones se realizan típicamente en "puntos de historia", utilizando
técnicas como PLANNING POKER para llegar a un consenso.
