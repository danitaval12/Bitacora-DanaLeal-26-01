### PATRONES DE DISEÑO - A LA PRACTICA

#### CREACIONAL - FACTORY METHOD
Es un patrón de diseño creacional que proporciona una interfaz para crear objetos en una superclase, mientras permite a las subclases alterar el tipo de objetos que se crearán.
- Evitas un acoplamiento fuerte entre el creador y los productos concretos.
- Se presenta el principio de **S** ya que, puedes mover el código de la creación de un producto o un lugar del programa haciendolo más facil de mantener.
- Se presenta el principio de **O** al incorporar nuevos tipos de productos en el programa sin descomponer el código cliente existente.
<img width="753" height="365" alt="image" src="https://github.com/user-attachments/assets/11b4c6ff-2c56-438a-b3ec-413bcfcc65b9" />

#### CREACIONAL - ABSTRACT FACTORY

Es un patrón de diseño creacional que nos permite producir familias de objetos relacionados sin especificar sus clases concretas.
- Puedes tener la certeza de que los productos que obtienes en una fabrica son compatibles entre si.
- Evitas un acoplamiento frente productos y código cliente.
<img width="717" height="359" alt="image" src="https://github.com/user-attachments/assets/8f4f7230-be4a-4d2d-adec-4117185be379" />

#### CREACIONAL - BUILDER 
Es un patrón de diseño creacional que nos permite construir objetos complejos paso a paso. EL patrón nos permite producir distintos tipos y representaciones de un objeto empleando el mismo código de construcción.

#### ESTRUCTURAL - ADAPTER
Es un patrón de diseño estructural que permite la colaboración entre objetos con interfaces incompatibles.

#### ESTRUCTURAL - BRIDGE
Es un patrón de diseño estructural que te permite dividir una clase grande, oun grupo de clases estrechamente relacionadas, en dos jerarquías separadas (abstracción e implementación) que pueden desarrollarse independientemente la una de la otra.

#### ESTRUCTURAL - COMPOSITE
Es un patrón de diseño estructural que te permite componer objetos en estrucutras de árbol y trabajr con esas estrucutras como si fueran objetos individuales.
